# RpGenx Meta Photo Converter — GitHub Build Ready

This repository is prepared for a phone-only GitHub Actions build.

## Build from an Android phone

1. Create a GitHub repository.
2. Upload the contents of this project to the repository root.
3. Open **Actions**.
4. Select **Build RpGenx APK**.
5. Tap **Run workflow**.
6. Wait for the workflow to finish.
7. Open the successful run and download the **RpGenx-debug-apk** artifact.
8. Extract the downloaded ZIP and install `RpGenx_Meta_Photo_Converter.apk`.

## Included
- RpGenx mobile HTML converter
- 3024 × 4032 JPEG output
- Meta EXIF injection
- Camera/gallery support
- Web Share / Android share sheet
- Offline/local processing
- GitHub Actions Android APK build

The APK is a debug build and is intended for personal testing/distribution. No Android Studio is required on the phone when using GitHub Actions.
